🌱 Crop_AI: Intelligent Crop Recommendation System

An AI-powered crop recommendation system that suggests the most suitable crop based on soil and environmental parameters, helping improve agricultural productivity and promote data-driven farming decisions.

📌 Project Overview

Crop_AI leverages Machine Learning to analyse critical agricultural inputs such as soil nutrients and climatic conditions to recommend the optimal crop for cultivation.
The system is designed to support precision farming, reduce crop failure risk, and enhance sustainable agricultural practices.

This project was developed and deployed using IBM Watsonx.ai Studio, demonstrating an end-to-end ML workflow from training to deployment.

🚀 Key Features

🌾 Intelligent crop prediction using Machine Learning

📊 Input parameters:

Nitrogen (N)

Phosphorus (P)

Potassium (K)

Temperature

Humidity

pH level

Rainfall

🧠 Multiclass classification using Random Forest

☁️ Deployed on IBM Cloud (Watsonx.ai Studio)

🔌 API-based prediction support

📈 Accurate, scalable, and deployment-ready model

🧠 Machine Learning Model

Algorithm Used: Random Forest Classifier

Reason for Selection:

Handles non-linear relationships effectively

Robust to noise and overfitting

Suitable for multiclass crop prediction problems
